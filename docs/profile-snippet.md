### Quorum Lab · 共识观测台

独立实现五节点 Raft 协议，把网络分区、双领导者与日志修复做成六幕可交互实验。

- TypeScript 确定性事件引擎、Web Worker、空间网络与实时副本证据。
- 实际 RPC 载荷/投递状态检查、逐事件调试、精确回放与分支对照。
- 崩溃恢复、乱序、丢包、冲突日志修复与运行时安全检测。
- 消息执行分支与接收端前后切片、单向链路故障、精确回放。
- 对抗消息调度、真实 RPC 谱系、重复选票去重证明与旧确认乱序实验。
- 33 项协议测试、66 项多浏览器验收用例（每浏览器 22 项）、100 种混合故障精确回放与云端发布门禁。
- 独立复审两处消息谱系/选票上下文回归：旧 UI 2/2 失败，修复后三浏览器 6/6 无重试通过；增强最终应用收敛检查与便携服务身份验收。

v0.4 最终本地 66/66 浏览器验收零重试通过；云端发布仍待门禁完成。执行状态见 [验收记录](validation.md)。
